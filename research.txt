Research & Strategy:

- Primary Quantitative Risks: Phantom liquidity, API architecture constraints (Event vs Market ID), Microstructure risk (empty L2 orderbooks on directional algorithms).


Data :

- Execution Data: Spread endpoint, L1 Imbalance (Top of Book volume).
- Underlying Data: Real-time BTC prices for ML inference.


Features :
- Raw Inputs: Short-term OHLCV (1m/15m).
- Engineered Predictors: High-frequency momentum, volatility contraction.


Training :
Phase 1: Primary Model (Probability Prediction)

Phase 2: Meta-Labeling (Confidence Thresholding)
- Architecture: Random Forest Classifier.
- Output: Dynamic probability thresholding to match Polymarket share pricing (e.g., executing only if LGBM confidence > Market Ask Price).


Live Diagnosis & Execution Analysis :
- Diagnostic scripts (`poly_scanner.py`, `top_markets.py`) deployed to scan CLOB API in real-time.
- Finding 1: Discrepancy between Web UI aggregated liquidity and actual CLOB API orderbook.
- Finding 2: Lack of institutional Market Makers on pure short-term directional contracts.
- Spread Analysis: Target market (BTC 4 PM ET) showed a spread of 0.98$ (Best Bid: 0.01$ | Best Ask: 0.99$).
